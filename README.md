## Установка
```
git clone https://github.com/almsar99/online-store.git
```
## Создание виртуального окружения
```
python3 -m venv venv
source venv/bin/activate
```
## Установка зависимостей
```
pip install -r requirements.txt
```
## Настройка .env
Создайте файл `.env` в корне проекта:
```
DB_NAME=online_store
DB_USER=postgres
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5432
```

## Запуск проекта
```
python manage.py runserver
```
## Открыть в браузере
```
http://127.0.0.1:8000/
```
## Миграции
```
python manage.py makemigrations
python manage.py migrate
```

## Создание суперпользователя
```
python manage.py createsuperuser
```

## Загрузка фикстур
```
python manage.py fill
```

## Создание групп и прав
```
python manage.py create_groups
```
## Кеширование и Redis
В проекте используется Redis для кеширования:
- кеширование детальной страницы продукта
- низкоуровневое кеширование списка продуктов по категории
- TTL кеша — 15 минут

### Установка Redis (macOS)
```
brew install redis
```

### Запуск Redis
```
brew services start redis
```
### Проверка Redis

```
redis-cli ping
```

Ожидаемый результат:
```
PONG
```

## Блог
Доступные страницы блога:
- `/blogs/` — список статей
- `/blogs/create/` — создание статьи
- `/blogs/view/<id>/` — просмотр статьи
- `/blogs/update/<id>/` — редактирование статьи
- `/blogs/delete/<id>/` — удаление статьи

## Права доступа и модерация
Реализована система ролей и разграничения доступа:

### Модератор продуктов
Пользователь группы «Модератор продуктов» может:
- одобрять продукты
- отклонять продукты
- оставлять комментарий модератора
- снимать продукты с публикации
- удалять продукты


### Контент-менеджер
Пользователь группы «Контент-менеджер» может:
- создавать статьи
- редактировать статьи
- удалять статьи

### Владельцы продуктов
- продукт автоматически привязывается к автору
- только владелец может редактировать свой продукт, если продукт не опубликован
- удалить продукт может владелец или модератор

### Статусы товаров
Товары поддерживают несколько статусов:
- черновик
- на проверке
- опубликован
- отклонен
